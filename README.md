# Data Explorer Pro - Snowflake Streamlit App

## App Name
DATA EXPLORER PRO

## Description
This is a Snowflake Streamlit application for data exploration and analysis.

## Features
- Upload file
- Load from Snowflake table
- Load from stage
- Load marketplace dataset
- Data preview and filtering
- Charts and visualization
- SQL Assistant
- Ask Your Data (AI)
- Export data
- Data Masking
- Database Explorer
- Internal Marketplace
- Apps overview
- External data
- Data sharing
- Governance & security

## Tech Stack
- Python
- Streamlit
- Snowflake Snowpark

## Note
This app runs inside Snowflake Streamlit environment.
